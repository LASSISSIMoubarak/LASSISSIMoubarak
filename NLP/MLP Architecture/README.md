# MLP Architecture

Ce dossier contient `mlp.py` et `mlflow_functions.py`, scripts d'étude d'un
perceptron multicouche et du suivi de ses expériences. Le code MLflow attend
notamment les modules `item` et `mlflow`, ainsi qu'un serveur de suivi démarré
séparément.

Les dépendances, le point d'entrée et les exemples d'exécution ne sont pas
encore fournis ici. Consulte les imports et paramètres des scripts avant usage ;
ce dossier n'est pas présenté comme un pipeline autonome tant que ces éléments
ne sont pas documentés.
