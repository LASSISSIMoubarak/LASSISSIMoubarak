# Statistiques

Ce dossier rassemble des exercices de statistiques, de programmation et de
traitement de données :

- [Big data](<./Big data/README.md>) — exercices Python sur la concurrence,
  l'IPC, Hadoop et PySpark.
- `Data challenge/` — notebook et script d'analyse d'un challenge.
- `TPEXO1/` — notebook d'exercice de régression et fichiers d'entrée/sortie
  locaux.

Les jeux de données et résultats CSV ne sont pas tous versionnés. Consulte les
instructions des sous-dossiers et vérifie que les entrées locales sont
disponibles avant exécution.
