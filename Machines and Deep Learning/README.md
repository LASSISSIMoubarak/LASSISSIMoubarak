# Machines et Deep Learning

Collection de notebooks d'étude en apprentissage automatique et deep learning.
Les notebooks sont conservés à la racine pour l'instant ; leurs dépendances et
leurs données d'entrée peuvent varier d'un exercice à l'autre.

## Notebooks

- Arbres et ensembles : `CART_BaggedTree.ipynb`,
  `Random_forest_model.ipynb`.
- Approximation par noyaux : `Kernel_approximation.ipynb`.
- Réseaux et vision : `Classification_with_neural_network.ipynb`, `TP_CNN.ipynb`,
  `TP_Image_detection.ipynb`, `TP-Image_segmentation.ipynb`.
- Séries d'activité : `TP-HumanActivity-Classification.ipynb`.
- Données NetCDF : `NetCDF_dicovery (1).ipynb`.
- Physics-informed machine learning : `PIML.ipynb`.
- Autres notebooks : `OPTIMAL.ipynb` et
  `TP-MoubarakLASS-LDA-NBC-ppv-checkpoint.ipynb`.

Ouvre les notebooks avec Jupyter et exécute leurs cellules dans l'ordre. Les
entrées externes et les bibliothèques doivent être vérifiées dans chaque
notebook ; aucun environnement commun n'est encore défini. Le notebook dont le
nom contient `checkpoint` est conservé tel quel et mérite une vérification
manuelle avant d'être présenté comme un projet final.
