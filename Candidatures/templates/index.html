Navigateur

Extension « Enregistrer l’offre »

Sur une offre LinkedIn, Indeed ou autre déjà ouverte dans ton navigateur, un clic l’envoie ici avec sa description complète.

  1. Dans Edge ou Chrome : edge://extensions (ou chrome://extensions) → active le mode développeur → « Charger l’extension non empaquetée » → dossier Candidatures\extension.
  2. Ouvre une offre, clique sur l’icône de l’extension, colle ce jeton une seule fois, puis « Enregistrer cette offre ».
