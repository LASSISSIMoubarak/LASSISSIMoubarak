# Spark et MapReduce

Deux notebooks d'exercices sont regroupés dans ce dossier :

- [MapReduce](<./Map_reduce/Moubarak_LASSISSI__MapReduce.ipynb>) — exercice
  d'analyse avec un traitement de type mapper/reducer.
- [PySpark](<./PySpark/04_pyspark_movie_exercises.ipynb>) — exercices de
  chargement, transformation et agrégation avec Spark SQL.

Les dépendances attendues sont propres à chaque notebook. Le notebook PySpark
nécessite Java et PySpark ; les exercices Hadoop Streaming nécessitent une
distribution Hadoop si les cellules exécutent un vrai job. Ouvre les notebooks
et vérifie leurs premières cellules pour les jeux de données requis. Les
données ne sont pas fournies par ce README.

Des notebooks apparentés existent aussi dans
`Statistiques/Big data/Hadoop/` ; ils sont conservés séparément et peuvent avoir
évolué indépendamment.
